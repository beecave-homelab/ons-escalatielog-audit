Her-escalatie

Een nieuwe poging binnen aangenomen actieve toegang

Dezelfde medewerker, dezelfde herkenbare cliënt. We vergelijken Start B met de eerdere geldige Activatie A.

08:00 · Start AEerdere poging
08:02 · Activatie ABegin aangenomen toegang
09:10 · Start BNieuwe poging, 68 min. later
22:02 · EindgrensActivatie A + 840 min.
Aangenomen toegang: 840 minuten vanaf Activatie A. Een start precies op de eindgrens telt mee.

Schematisch, niet op tijdschaal. De log bewijst niet dat toegang werkelijk nog actief was. Het zeer-snel-signaal gebruikt de afstand Start A–Start B; hier 70 minuten, dus niet binnen de ingestelde 5 minuten.

09:10 ligt binnen het venster: her-escalatie.

Peer-ratio’s

Zo lees je de ratio

13 escalaties ÷ groepsmediaan 6 = ratio 2,17. De mediaan is berekend over andere vergelijkbare medewerkers.

0,50 = de helft van de mediaan; 1,00 = gelijk; 2,00 = tweemaal de mediaan. Dit zijn referentiepunten, geen alarmdrempels. Een hogere ratio betekent geen evenredig hogere werklast of risico.
